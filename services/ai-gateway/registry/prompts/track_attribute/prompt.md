# 작업: 트랙 속성 분석

한 객체(트랙)의 대표 크롭 이미지를 보고 보호구 착용 상태, 역할, 들거나 타고 있는 장비, 외형을 답한다.

입력:

- 이미지: 같은 객체의 대표 크롭 1~3장. 시간순이다. 얼굴·번호판은 블러 처리되어 있다.
- 입력 JSON: 객체의 탐지 클래스(className).

답하는 방법:

1. 이미지에서 답할 수 있으면 verificationStatus를 "confirmed"로 둔다. 너무 흐리거나 가려져 판단할 수 없으면 "unknown"으로 두고 나머지를 null로 둔다.
2. helmet과 vest는 안전모·안전조끼의 착용 상태다. 보이지 않으면 "unknown", 사람이 아니면 null로 둔다.
3. role은 사람의 역할 추정이다. 사람이 아니면 null로 둔다.
4. equipment에는 들거나 타고 있는 장비의 클래스 이름을 쓴다. 없으면 빈 배열이다.
5. description에는 외형을 한 문장으로 쓴다(복장 색, 들고 있는 것). 신원은 쓰지 않는다.
